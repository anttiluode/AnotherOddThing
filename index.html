The pulse is not the computation.

A tiny event can interrogate resident dynamics. v2 adds a missing layer: a compartment-shared analog state between the connection and the branch, read both for what is expressed now and for what is allowed to change later.

event + address + local context → shared compartment state → { expression now, plasticity later } → resident dynamics

v2 · the local trace is shared by a compartment

A short filter follows local drive; a slower filter follows the short one. The slow level is thresholded into no-change / LTD / LTP. Fast minus slow is a free rise/fall indicator.

Pulse microscope

Three regimes from two thresholds

slow < 0.10 → 0
0.10 ≤ slow < 0.32 → LTD
slow ≥ 0.32 → LTP

Default filters: 15 ms fast, 45 ms slow, `dt = 5 ms`.

The toy deliberately mixes a Yang-like thresholded level readout with an Onasch-inspired two-timescale state. It is not a reproduction of either biological rule.

Claim fence

The coupled trace does not beat a perfectly mirrored decoupled trace.

The supported statement is narrower: sharing the local coordinate removes one routing/alignment requirement. If expression and plasticity are represented independently, somebody has to keep those coordinates aligned.

Yang et al. motivate nonlinear branch expression and calcium-threshold plasticity; Onasch et al. motivate local voltage filters, branch-level plasticity and heterosynaptic normalization; Vollan et al. motivate small control signals moving an already resident representation. None establish this synthetic v2 result.
